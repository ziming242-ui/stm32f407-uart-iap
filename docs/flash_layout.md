# STM32F407ZGT6 Flash 分区说明

## 1. 证据与设计边界

- [官方手册] STM32F407ZG 主 Flash 容量为 1 MiB，地址范围为 `0x08000000`～`0x080FFFFF`。
- [官方手册] 扇区 0～3 各 16 KiB，扇区 4 为 64 KiB，扇区 5～11 各 128 KiB；内部 Flash 的最小擦除单位是整个扇区。
- [文档设计] 本演示采用下述 Boot、参数、运行、A、B 五区。这是一种针对本项目的布局，不是 STM32F407 的固定用法。
- [开发板实测待补] 尚需使用 Keil `.map`、下载日志和 Memory 窗口核对各区域的真实内容。

## 3. 五区布局

以下范围使用“起始地址包含、结束地址不包含”的表示方法。

| 区域 | 扇区 | 地址范围 | 容量 | 用途 |
|---|---:|---:|---:|---|
| Boot | 0～4 | `[0x08000000, 0x08020000)` | 128 KiB | 二级 Bootloader、UART 协议、Flash 驱动、校验和跳转 |
| Param | 5 | `[0x08020000, 0x08040000)` | 128 KiB | 镜像状态、版本、长度、CRC、升级进度和确认记录 |
| Run | 6～7 | `[0x08040000, 0x08080000)` | 256 KiB | APP 的唯一链接和执行区域 |
| Slot A | 8～9 | `[0x08080000, 0x080C0000)` | 256 KiB | 一个完整候选或已确认镜像 |
| Slot B | 10～11 | `[0x080C0000, 0x08100000)` | 256 KiB | 另一个完整候选或已确认镜像 |

五区容量之和正好为 1 MiB，因此本布局没有未分配扇区，也没有备用扇区。

## 4. 固件链接关系

- [文档设计] Bootloader 的 Keil IROM1 起始地址为 `0x08000000`，大小为 `0x00020000`。
- [文档设计] APP 的 Keil IROM1 起始地址为 `0x08040000`，大小为 `0x00040000`。
- [文档设计] APP 的向量表地址和 `SCB->VTOR` 都必须使用 `0x08040000`。
- [文档设计] A、B 槽不直接执行，也不分别生成两个链接地址不同的 APP。
- [文档设计] Qt 上位机发送的是同一个按 `0x08040000` 链接生成的 APP `.bin`。Bootloader 可把相同 `.bin` 写入 A 或 B，再搬运到 Run 区后启动。
- [文档设计] APP 镜像长度必须大于 0 且不超过 `0x00040000` 字节。实际工程还要由 `.map` 和 `.bin` 大小证明没有越界。

如果直接跳到 A 区或 B 区，而镜像仍按 `0x08040000` 链接，绝对地址、向量表和常量位置会不匹配。因此本演示只允许从 Run 区执行。

## 5. 向量合法性范围

Run 区前两个 32 位字分别作为初始 MSP 和 Reset Handler 地址。

- [官方手册] SRAM1 的数据地址为 `0x20000000`～`0x2001BFFF`，SRAM2 为 `0x2001C000`～`0x2001FFFF`。
- [文档设计] 当前 APP 使用主 SRAM，Bootloader 接受的初始 MSP 应落在主 SRAM 范围内；栈顶边界值可以是 `0x20020000`。
- [文档设计] 不要假定首向量必然等于 `0x20020000`。实际数值由 APP 的 RAM 配置、栈大小和链接结果决定。
- [文档设计] MSP 需满足工程采用的栈对齐要求，本演示按 8 字节对齐检查。
- [文档设计] Reset Handler 的最低位必须为 1，表示 Thumb 状态；清除最低位后的地址必须位于已接收 APP 的有效 Run 区范围内。
- [开发板实测待补] 使用 Keil Memory 窗口读取 `0x08040000` 和 `0x08040004`，并与 APP `.map` 中的栈顶和 `Reset_Handler` 对照。

## 6. 擦写规则与限制

1. Bootloader 不得擦除扇区 0～4，否则会删除自身。
2. 下载新固件时只擦除选中的非活动 A/B 槽；另一个已确认槽在新 APP 健康确认前必须保留。
3. 搬运前先校验槽内完整镜像，搬运后再校验 Run 区。
4. 写入地址、长度和 `地址 + 长度` 都必须做溢出及区域边界检查。
5. Param 区更新采用 128 字节追加记录、序号和 CRC；先写内容与 CRC，最后写独立提交标记。复位发生在提交标记之前时，该记录无效。不能把普通布尔变量当作掉电安全事务。
6. 本布局没有备用扇区。Param 扇区写满后若要整扇区擦除并压缩记录，掉电安全会成为单独问题；在没有外部存储或重新划分扇区前，不得宣称参数区压缩具备工业级断电保护。
